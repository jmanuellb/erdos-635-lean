# Erdős Problem 635 in Lean 4

Lean 4 / Mathlib proofs about [Erdős Problem 635](https://www.erdosproblems.com/635), and a
short mathematical note with an improved upper bound.

## The problem

Let `t ≥ 1` and let `A ⊆ {1, …, N}` be a set such that whenever `a < b` are in `A` with
`b − a ≥ t`, the difference `b − a` does not divide `b`. How large can `|A|` be? Is it true that
`|A| ≤ (1/2 + o_t(1)) N`?

Write `M(t, N)` for the largest size of such a set. The second question was answered in the
affirmative in January 2026 (see [Prior work](#prior-work)). The first question, the true size of
`M(t, N) − N/2`, is open. This repository does not solve it.

## What is in this repository

1. **Lean, first order** (`E635/Main.lean`, `E635/LowerBound.lean`): `|A| ≤ (1/2 + ε) N` for
   large `N` (`erdos_635`), the lower bound `⌈N/2⌉` from the odd numbers (`erdos_635_lower`),
   hence `M(t, N) ~ N/2` (`erdos_635_isEquivalent`), and `M(1, N) = ⌈N/2⌉` (`erdos_635_t_one`).
   These results were known and had already been formalized in Lean by someone else
   (see [Prior work](#prior-work)). This is an independent second formalization.
2. **Lean, finite core of a sharper bound** (`E635/Lines.lean`, `E635/DoubleCount.lean`,
   `E635/Weights.lean`, `E635/FiniteBound.lean`): the explicit inequality
   `M(t, N) ≤ ⌈N/2⌉ + |B₁| + |B₂|` for all `t`, `N` (`E635.maxAdmissible_le_B1_B2`), where `B₁`
   and `B₂` are explicit finite sets. This is a purely combinatorial statement. As far as we
   know it has not been formalized before.
3. **Note, not formalized** ([`note/note.tex`](note/note.tex), [`note/note.md`](note/note.md)):
   a written proof that `M(t, N) ≤ N/2 + (c₀ + o(1)) N / log N` (Theorem A) and
   `M(t, N) ≤ N/2 + 3N·exp(−0.15 √(log N))` for large `N` (Theorem B).

**What Lean checks and what it does not.** Of the note, Lean checks only Lemmas 2.2 and 2.3 and
inequality (1) of Theorem A, that is, item 2 above. The estimates of `|B₁|` and `|B₂|` (Rankin's
trick, prime counting), and all of Theorem B, exist only as a written proof in the note. So the
bound `N/2 + O(N·exp(−c √(log N)))` is **not** formally verified. It has not been refereed by a
human expert either.

The repository does **not** determine `M(t, N)` for `t ≥ 2` (where it can exceed `⌈N/2⌉`, e.g.
`M(2, 14) = 9`). The lower bound `⌈N/2⌉ + Θ_t(log N)` for `t ≥ 2` (Erdős's construction with the
powers `2^k`, `k` odd) is discussed in the note but is not formalized here.

## Prior work

* **The answer to the second question.** The problem page records that the question
  `|A| ≤ (1/2 + o_t(1)) N` "has been resolved in the affirmative by ChatGPT-5.2 (prompted by
  Leeham)". The proof was posted by Liam Price in the
  [forum thread](https://www.erdosproblems.com/forum/thread/635#post-3958) on 30 January 2026.
  Terence Tao observed in the same thread that the statement follows quickly from an inequality
  of Elliott (*Probabilistic Number Theory I*, 1979, Lemma 4.7).
* **Earlier Lean proof.** The same forum post links a Lean 4 proof generated by Aristotle
  (Harmonic), for Lean `v4.24.0`. According to its header it proves the upper bound
  `|A| ≤ (1/2 + o(1)) N`, that the odd numbers are admissible, a lower-bound construction of size
  about `N/2 + log₂(N)/2` for `t ≥ 2`, and the exact maximum `⌈N/2⌉` for `t = 1`. It therefore has
  priority over item 1 above, and it contains a lower-bound construction that this repository
  does not formalize. That proof was not consulted while this formalization was written. We read
  its header and list of declarations afterwards, to describe it here. We did not compile it.
* **Best earlier explicit error term.** Zheng, Zhang, Avigad, Tetali and Welleck,
  [arXiv:2608.16977](https://arxiv.org/abs/2608.16977), Appendix C.4, Theorem C.4.1, prove
  `⌈n/2⌉ ≤ M(t, n) ≤ n/2 + 3n/√(log log n)` for `n ≥ n₀(t)`. Tao remarked in the forum that
  Elliott-type arguments give an error of order `N / log log N`.
* **What is new here, to our knowledge.** The upper bounds of the note: error terms of order
  `N / log N` (Theorem A) and `N·exp(−c √(log N))` (Theorem B) in place of `N/√(log log N)`. We
  found no earlier bound of this strength in the sources above. We did not have access to
  Guy (1983), Ruzsa (1999) or the text of Elliott's book, so we cannot exclude that a stronger
  bound is in the older literature. Only the finite core of Theorem A is formalized (item 2).
  The gap to the lower bound `N/2 + Θ_t(log N)` remains very large.

## Lean statements

### Upper bound

File `E635/Main.lean`, theorem `erdos_635` (root namespace):

```lean
theorem erdos_635 (t : ℕ) (ht : 1 ≤ t) :
    ∀ ε > 0, ∀ᶠ N in Filter.atTop, ∀ A : Finset ℕ, A ⊆ Finset.Icc 1 N →
      (∀ a ∈ A, ∀ b ∈ A, a < b → t ≤ b - a → ¬ (b - a ∣ b)) →
      (A.card : ℝ) ≤ (1 / 2 + ε) * N
```

`o_t(1)` is rendered as "for every `ε > 0`, for all sufficiently large `N`", with the threshold
allowed to depend on `t` and `ε`. Since `a < b`, the natural-number subtraction `b - a` is the true
difference. The hypothesis `ht` is not used by the proof (the statement also holds for `t = 0`);
it is kept to match the problem.

### Lower bound, extremal function, asymptotic, `t = 1`

File `E635/LowerBound.lean` (root namespace unless prefixed by `E635.`):

```lean
theorem erdos_635_lower (t : ℕ) (_ht : 1 ≤ t) (N : ℕ) :
    ∃ A : Finset ℕ, A ⊆ Finset.Icc 1 N ∧
      (∀ a ∈ A, ∀ b ∈ A, a < b → t ≤ b - a → ¬ (b - a ∣ b)) ∧
      A.card = (N + 1) / 2 ∧ (N : ℝ) / 2 ≤ A.card

noncomputable def E635.maxAdmissible (t N : ℕ) : ℕ :=
  ((Icc 1 N).powerset.filter (fun A => Good t A)).sup card

theorem E635.maxAdmissible_eq_iff {t N m : ℕ} :
    maxAdmissible t N = m ↔
      (∃ A : Finset ℕ, A ⊆ Icc 1 N ∧
        (∀ a ∈ A, ∀ b ∈ A, a < b → t ≤ b - a → ¬ (b - a ∣ b)) ∧ A.card = m) ∧
      (∀ A : Finset ℕ, A ⊆ Icc 1 N →
        (∀ a ∈ A, ∀ b ∈ A, a < b → t ≤ b - a → ¬ (b - a ∣ b)) → A.card ≤ m)

theorem erdos_635_isEquivalent (t : ℕ) (ht : 1 ≤ t) :
    (fun N : ℕ => (E635.maxAdmissible t N : ℝ)) ~[Filter.atTop] (fun N : ℕ => (N : ℝ) / 2)

theorem erdos_635_t_one (N : ℕ) : E635.maxAdmissible 1 N = (N + 1) / 2
```

`(N + 1) / 2` is natural-number division, i.e. `⌈N/2⌉`. `E635.Good t A` is the hypothesis of the
problem, spelled out verbatim in `maxAdmissible_eq_iff` (the defining property of the maximum, split
into `card_le_maxAdmissible` and `exists_card_eq_maxAdmissible`). `~[Filter.atTop]` is Mathlib's
`Asymptotics.IsEquivalent`: `M(t, N) − N/2 = o(N/2)`.

### Finite core of the explicit bound `M(t, N) ≤ ⌈N/2⌉ + |B₁| + |B₂|`

Files `E635/Lines.lean`, `E635/DoubleCount.lean`, `E635/Weights.lean`, `E635/FiniteBound.lean`
(namespace `E635`). `lines T n` is the set of primes `p ≥ T` dividing `n`; `odds N` is the set of
odd numbers in `[1, N]`.

```lean
theorem one_per_line {t : ℕ} {A : Finset ℕ} (hgood : Good t A) {o p : ℕ}
    (ho : o % 2 = 1) (hp : 0 < p) (hpt : t ≤ p) (hpo : p ∣ o) (hlt : p < o) :
    ¬ (o - p ∈ A ∧ o + p ∈ A)

-- weight systems: w ≥ 0 and ∑_{p ∈ lines T o} w o p ≤ 1 for every o ∈ odds N
def IsWeight (T N : ℕ) (w : ℕ → ℕ → ℝ) : Prop :=
  (∀ o p, 0 ≤ w o p) ∧ ∀ o ∈ odds N, ∑ p ∈ lines T o, w o p ≤ 1
noncomputable def cov (T N : ℕ) (w : ℕ → ℕ → ℝ) (e : ℕ) : ℝ :=
  ∑ p ∈ lines T e, (w (e - p) p + if e + p ≤ N then w (e + p) p else 0)

theorem card_le_of_weight {t T N : ℕ} (htT : t ≤ T) (hT : 3 ≤ T) {w : ℕ → ℕ → ℝ}
    (hw : IsWeight T N w) {A : Finset ℕ} (hA : A ⊆ Icc 1 N) (hgood : Good t A) :
    A.card ≤ (N + 1) / 2 + (A.filter (fun e => e % 2 = 0 ∧ cov T N w e < 1)).card

theorem maxAdmissible_le_of_weight {t T N : ℕ} (htT : t ≤ T) (hT : 3 ≤ T)
    {w : ℕ → ℕ → ℝ} (hw : IsWeight T N w) :
    maxAdmissible t N ≤ (N + 1) / 2 + (badSet T N w).card

-- B1 T N = {e ∈ [1, N] : e even, 2 · rad_{≥T}(e)² < 3e}
-- B2 T N = {p · (N / p) : p prime, T ≤ p, 4p ≤ N, N / p even}
theorem badSet_subset {T N : ℕ} (hT : 3 ≤ T) : badSet T N (logWeight T) ⊆ B1 T N ∪ B2 T N

theorem maxAdmissible_le_B1_B2 {t T N : ℕ} (htT : t ≤ T) (hT : 3 ≤ T) :
    maxAdmissible t N ≤ (N + 1) / 2 + (B1 T N).card + (B2 T N).card
```

`badSet T N w` is `{e ∈ [1, N] : e even, cov T N w e < 1}` and `logWeight T o p = log p / log rad_{≥T}(o)`
(the weights of Theorem A of the note in `note/`; take `T = max t 3`). The analytic estimates of
`|B₁|` and `|B₂|` (Rankin's trick, prime counting) are not formalized. Theorem B of the note is
not formalized at all.

## Proof outline

This outline is for the first-order results (item 1). The full write-up is in
[`docs/PROOF.md`](docs/PROOF.md); the Lean files follow it step by step. The proof of the finite
core (item 2) is in Sections 2 and 3 of the note.

1. Fix a **finite** set `P` of primes `≥ t` with `μ = Σ_{p∈P} 1/p` large (possible because
   `Σ 1/p` diverges, `not_summable_one_div_on_primes`). `P` depends only on `t` and `ε`.
2. For `p ∈ P`, the multiples of `p` in `A` and their translates by `p` are disjoint (a pair
   `a, a + p` would violate the hypothesis), so `A` contains at most `(⌊N/p⌋ + 1)/2` multiples of `p`.
3. Double counting: with `w(n) = #{p ∈ P : p ∣ n}`, `Σ_{a∈A} w(a) ≤ Nμ/2 + |P|/2`.
4. A Turán–Kubilius type variance bound for the fixed set `P`:
   `Σ_{n≤N} (w(n) − μ)² ≤ Nμ + 2μ|P|`.
5. The pointwise inequality `μ − w ≤ (w − μ)²/s + s/4` (`s > 0`) bounds the total deficiency
   `Σ_{a∈A} (μ − w(a))` by `(Nμ + 2μ|P|)/s + Ns/4`.
6. Adding 3 and 5: `|A|·μ ≤ Nμ/2 + |P|/2 + (Nμ + 2μ|P|)/s + Ns/4`.
7. Taking `μ ≥ 4/ε² + 1`, `s = 4/ε` and `N ≥ ⌈|P|/(εμ) + |P|⌉` gives `|A| ≤ (1/2 + ε) N`.

All error terms are constants `O(|P|)`; no asymptotics of prime sums beyond divergence are needed.

Lower bound and asymptotic (`docs/PROOF.md`, Part II):

8. If `a < b` are odd, `b − a` is even and `b` is odd, so `b − a ∤ b`: the odd numbers in `[1, N]`
   are admissible for every `t`, and there are `⌈N/2⌉ ≥ N/2` of them.
9. Hence `N/2 ≤ M(t, N) ≤ (1/2 + ε) N` eventually, i.e. `M(t, N) ~ N/2`.
10. For `t = 1`, no two consecutive integers lie in `A` (`1 ∣ k + 1`), so `a ↦ (a − 1)/2` is
    injective from `A` into `[0, ⌈N/2⌉)`, giving `M(1, N) = ⌈N/2⌉`.

## Reproduction

```bash
# with elan installed
lake exe cache get     # download prebuilt Mathlib oleans
lake build             # builds the E635 library, including E635/Axioms.lean
```

The build ends with `Build completed successfully`. It prints deprecation and style-linter
warnings, and no errors. To typeset the note: `tectonic note/note.tex` (or any LaTeX with `amsart`).

On a heavily loaded Windows machine, building several modules that import `Mathlib` in parallel
occasionally failed with a spurious `failed to read file '…/Mathlib/….olean.private'`. Building
the modules one at a time (`lake build E635.<Module>`, then `lake build`) worked.
